      Access
      
            
      The access token is WEB_TOKEN — the unlock password for this console, written into secrets.env when you installed. Lost it? Run `./aidog secrets shell-env WEB_TOKEN | sed 's/^export WEB_TOKEN=//'` in your install folder shown below and paste the value; a whole `export WEB_TOKEN=…` line is fine too (the console unwraps it automatically). The command reads secrets.env even when the store is encrypted at rest — a plain `grep WEB_TOKEN secrets.env` prints nothing once E2 is on. Paste once and this browser remembers it; after that saving settings, approvals and service restarts all work. It cannot be changed from this page: to rotate it, edit WEB_TOKEN in secrets.env, then paste the new value here.
      
            
            
      
            
            
      Using this console on a phone or another machine: the server binds 127.0.0.1 only, so reach it through an SSH tunnel you control (for example ssh -L 19167:127.0.0.1:19167) — there is no cloud endpoint. Once the page answers over HTTPS it installs to your home screen as an app; over a plain http:// tunnel the browser will not offer the install.
