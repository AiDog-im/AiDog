COMMANDS

Telegram command reference

Commands run only in chats from your allowlist; anything else is ignored. Send /help in the bot to get the same list.

Command What it does
/helplist every command with one-line descriptions
/resetarchive this chat's session file and start fresh
/rewind [n] · /rewind (reply)drop the last n messages, or everything from the replied message onward (the old transcript is archived first)
/model [id]show this chat's model + endpoint host (never the key); set a per-chat override
/statussession turn count, current model, service uptime
/lang [code]show or switch the reply language (persisted service-wide)
/learn memory <text> · /learn skill <slug> :: <desc> :: <body>record one experience as an institutional artifact — the lint gate runs before any write
/reflect [daily|weekly|monthly]draft the period reflect skeleton (facts only — the conclusion is yours)
/evolutionself-evolution loop status: schedule, last runs, artifact counts
/cron [add [message|prompt] <spec> :: <text> | del <id>]natural-language cron jobs — add, list and delete; specs: every 30m · daily 08:00 · weekly mon 08:00 · once YYYY-MM-DD HH:MM (Beijing time)
/checkpoint [restore <id>]list file checkpoints and restore one (write_file/edit_file snapshot the previous file before every write)
/versioninstalled vs latest release — honest when the check fails

Local CLI

  • bash deploy/install.sh — one command: provision + boot + verify
  • aidog setup — guided wizard: fills the slots it lists, never echoes a value
  • aidog doctor — health gate the releases run green on
  • aidog update apply — upgrade: dirty-tree guard, fetch, fast-forward, service restart
